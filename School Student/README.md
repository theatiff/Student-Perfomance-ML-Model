# School Student Performance Dataset

## About the Dataset

This dataset contains information about school students and their performance in mathematics, reading, and writing. It is used to study how different student-related factors may affect academic performance.

## Dataset Details

* **Dataset Name:** Students Performance
* **Total Records:** 1,000
* **Total Columns:** 8
* **Target Column:** `math score`
* **Problem Type:** Regression

## Dataset Features

The dataset includes the following information:

| Feature                     | Description                                    |
| --------------------------- | ---------------------------------------------- |
| Gender                      | Student's gender                               |
| Race/Ethnicity              | Student's group                                |
| Parental Level of Education | Parents' education level                       |
| Lunch                       | Type of lunch                                  |
| Test Preparation Course     | Whether the student completed test preparation |
| Reading Score               | Student's reading marks                        |
| Writing Score               | Student's writing marks                        |
| Math Score                  | Student's mathematics marks                    |

## Target Variable

The `math score` column is used as the target variable.

The model uses student information, reading scores, and writing scores to predict mathematics scores.

## Dataset File

`Lower_Data.csv` contains 1,000 school student records used for analysis and machine learning.

## Data Source

The Students Performance dataset is available on Kaggle.

## Disclaimer

This dataset is used for educational and machine learning purposes. Predictions are estimates and should not be treated as guaranteed student results.
