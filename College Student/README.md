# College Student Performance Dataset

## About the Dataset

This dataset contains information about college students and their academic performance. It is based on the Higher Education Students Performance Evaluation dataset.

## Dataset Details

* **Dataset Name:** Higher Education Students Performance Evaluation
* **Total Records:** 145
* **Total Columns:** 33
* **Target Column:** `GRADE`
* **Problem Type:** Multi-class Classification

## Grade Categories

The `GRADE` column contains 8 categories:

| Grade | Result |
| ----- | ------ |
| 0     | Fail   |
| 1     | DD     |
| 2     | DC     |
| 3     | CC     |
| 4     | CB     |
| 5     | BB     |
| 6     | BA     |
| 7     | AA     |

## Dataset Features

The dataset includes information related to:

* Student background
* Academic performance
* Course details
* Study-related factors
* Student activities and other characteristics

## Dataset File

`Higher_Data.csv` contains the college student records used for analysis and machine learning.

## Data Source

UCI Machine Learning Repository: Higher Education Students Performance Evaluation.

## Disclaimer

This dataset is used for educational and machine learning purposes. The results obtained from it may not represent the academic performance of all college students.
